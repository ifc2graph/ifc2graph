# Dependencies

`ifc2graph` relies on the following open-source libraries:

## IfcOpenShell

[IfcOpenShell](https://docs.ifcopenshell.org/ifcopenshell.html) is used for geometry processing and clash detection. **License:** LGPL-3.0-or-later

## Neo4j Python Driver

[Neo4j Python Driver](https://github.com/neo4j/neo4j-python-driver) is used to connect to a Neo4j database and write the graph generated from the IFC model. **License:** Apache-2.0

## three.js

[three.js](https://github.com/mrdoob/three.js/) is used for rendering building elements in a web browser. **License**: MIT
